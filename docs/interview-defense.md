# Interview Defense

Be able to defend:
- why C++
- why build Git core yourself
- why layered architecture
- blobs/trees/commits/refs/HEAD
- object immutability
- filesystem vs PostgreSQL
- atomic writes
- crash recovery
- concurrent pushes
- authentication vs authorization
- path traversal protection
- CI isolation
- why consensus is not needed initially
- what breaks at 100,000 repositories / 10,000 users
- what can be recovered after HDD failure
- what you deliberately would not build in six months

Final challenge:
“Your design is too complicated for one machine. Convince me it isn't.”
Then defend every major component using invariants, trade-offs and failure behavior—not buzzwords.
