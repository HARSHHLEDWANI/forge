# Study Plan

Study just before the phase that needs the knowledge.

1. C++20: RAII, ownership, STL, filesystem, CMake, testing.
2. OS: files, processes, threads, system calls, locks, buffering, crashes, durability.
3. Git internals: blobs, trees, commits, refs, HEAD, index, DAGs, merge.
4. Algorithms: hash maps, graphs, DFS/BFS, diff, merge, indexing.
5. Databases: schema design, indexes, transactions, isolation, locking, migrations.
6. Networking: TCP/IP, sockets, HTTP, streaming, timeouts, TLS.
7. Security: path traversal, KDFs, public keys, tokens, sessions, RBAC, sandboxing.
8. Distributed systems: consistency, replication, CAP, Raft, idempotency.

For every topic:
Learn → explain without notes → build tiny experiment → use in Forge → test → defend in an interview.

Do not study distributed systems before the local architecture is working.
