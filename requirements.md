# Requirements

## Functional
Local repository creation, staging, status, commit, history, branches, checkout, diff, merge and conflict handling.

Content-addressed immutable object storage with integrity verification.

CLI supports direct commands and interactive discovery.

Future server supports remote operations, users, permissions and collaboration.

## Non-functional
- offline local mode
- configurable storage
- cross-platform core where practical
- stream large files
- safe paths
- atomic durable writes
- testable layers
- clear failure behavior
- security boundaries
